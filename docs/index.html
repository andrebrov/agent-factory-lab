Key Results

Batched Tool Calls

94.5% fewer tokens

Real (tiktoken)

Batch 20 file operations into one script instead of 20 separate API calls. Reduces requests from 20 to 2 and tokens from 32,981 to 1,819.

Prompt Caching

72.3% cost savings

Real token counts

Server-side caching of conversation prefixes over a 20-turn session. Cache hit rate: 92.7%. Break-even at turn 2.

Writer/Reviewer Pipeline

+15pp fix rate

Simulated

Cross-model writer + reviewer pipeline reduces defect escapes by 42% compared to single-agent, at +71% token cost.

Cheap Model Routing

20.9% cost savings

Estimated

Route orchestration to Claude Haiku ($0.25/M) instead of Opus ($15/M). Savings grow with orchestration-heavy sessions.

Parallel Pane Execution

1.83x speedup

Real (tmux)

Run edit, test, and log-check in parallel tmux panes. Session checkpoint/restore achieves zero state loss.

SuperPlane Pipeline

4/5 auto-shipped

Simulated

Backlog-to-ship state machine with risk gates: low-risk auto-merges, high-risk escalates to human review.

Stop Hook

0% reopen rate

Real (pytest)

Block "done" until tests pass. Catches all premature completion signals on buggy code; passes on fixed code.

Mutation Check

100% kill rate

Real (pytest)

Apply 10 deliberate mutations to fixed code. Every mutation was caught by at least one test. Runs in ~2 seconds.

Terse Completions

95.7% fewer output tokens

Real (tiktoken)

3-line completion report vs verbose summary: 18 tokens vs 415 tokens. Stop writing once verification passes.

HANDOFF.md

53% fewer tokens

Real (tiktoken)

60-line handoff summary vs full transcript for context transfer. Retains 100% of key facts.

Agent Races

60% → 91% success

Simulated

Race 3 models in parallel on hard tasks. 3x token cost but cost-per-success only ~2x due to higher success rate.

Remote VM Sessions

100% survival

Real (tmux)

tmux sessions survive 5 disconnect/reconnect cycles with zero state loss and sub-5ms reconnect.

What This Lab Is

Agent Factory Lab is a hands-on research repository for improving two coding agents:

  • Gwaihir — orchestrator for the herdr multi-agent coding tool
  • Landroval — orchestrator for the Rex coding factory

Findings are collected from X (Twitter), documented with source links, and each one has a runnable experiment you can clone and execute. Numbers are honestly labeled as real measurements, estimates, or simulations.

Quick Start

git clone https://github.com/andrebrov/agent-factory-lab.git
cd agent-factory-lab
pip install tiktoken pytest
bash run_all.sh

Each experiment writes a results.json and prints a human-readable summary. See the full report for consolidated analysis.
