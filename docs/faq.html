Frequently Asked Questions

Common questions about AI coding agent optimization, answered with real experiment data.

How much do batched tool calls reduce token usage for AI coding agents?

In our experiment with 20 file operations measured using tiktoken (cl100k_base encoding), batching all operations into a single script reduced total tokens from 32,981 to 1,819 — a 94.5% reduction. API requests dropped from 20 to 2 (90% reduction). The main savings come from eliminating repeated conversation context that grows quadratically with per-call approaches. Real measurement

How much does prompt caching save for long AI coding sessions?

Over a simulated 20-turn coding session with real token counts (tiktoken) and Anthropic pricing, prompt caching saved 72.3% of input costs. The cache hit rate was 92.7%, and the cache write premium was recovered by turn 2. Longer sessions save proportionally more. Real token counts

What is a writer/reviewer pipeline for AI coding agents?

A writer/reviewer pipeline uses separate AI models for writing code and reviewing it, similar to human code review. The writer produces a fix in an isolated git worktree, the reviewer checks it, and a QA step runs tests. A risk gate decides whether to auto-merge or escalate. In our Monte Carlo simulation (1,000 trials × 10 bugs), this improved fix rate by 15 percentage points and reduced defect escapes by 42%, at 71% higher token cost. Simulated

Does using cheap models for AI agent orchestration reduce quality?

Our cost model shows routing control-plane tasks to Claude Haiku ($0.25/M tokens) while keeping code generation on Claude Opus ($15/M) saves 20.9% of session cost. Quality risk is theoretically low for routing tasks, but this needs A/B testing on real coding tasks. Our experiment provides the framework. Estimated

Can AI coding agents run tasks in parallel using terminal panes?

Yes. Our tmux-based pane manager (~80 lines of Python) runs edit, test, and log-monitoring in parallel, achieving a 1.83x speedup over sequential execution. Session checkpoint/restore achieves zero state loss across simulated crashes. Real measurement

What is the SuperPlane pattern for automated coding?

SuperPlane automates the full lifecycle: issue → triage → plan → approve → execute → review → merge → deploy. Our state machine correctly routes issues by risk level: low-risk auto-merges, high-risk escalates, no-test issues are immediately escalated. 10 capabilities are needed for full implementation. Are these results real or simulated?

Three experiments produce real measurements: batched tool calls (94.5% via tiktoken), prompt caching (72.3% via tiktoken + pricing), and session layer (1.83x via real tmux). Three use simulations or estimates: writer/reviewer (Monte Carlo), model routing (cost model), SuperPlane (state machine). Every number is labeled. Nothing is fabricated.

What are Gwaihir and Landroval?

Gwaihir is the orchestrator for herdr, a multi-agent coding tool. Landroval is the orchestrator for Rex, a coding factory. Both are AI coding agents being improved through this research lab.

How do I run the experiments myself?

Clone the repo, install dependencies, and run the script:

git clone https://github.com/andrebrov/agent-factory-lab.git
cd agent-factory-lab
pip install tiktoken pytest
bash run_all.sh

Each experiment writes results.json and prints a summary. No API keys needed.
