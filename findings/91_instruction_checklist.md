# Finding 91: Instruction Checklist in Every "Done" Report

## Source
<https://x.com/HimanshuRawal05/status/2126512356167688625>

## Idea
Each lane's done report must list every instruction as done/skipped/blocked
with a reason. A report that omits items is rejected.

## Experiment
Checker parses task file + done report. Cases: complete reports, silently
skipped items, vague mentions. Cannot test against a live agent.
